# Theme contrast reference

WCAG 2.x contrast for the theme colours every FS.Skia.UI.Controls preview renders with,
computed by the shipped **FS.Skia.UI.Color** package (`Contrast.check` / `Contrast.ratio`)
over the DTCG single source (`src/Controls/design-tokens.tokens.json`). The controls docs
render against `DesignTokens.Light`; the dark theme is included for completeness. Text
pairings target AA body text (≥ 4.5:1); non-text/UI use WCAG 1.4.11 (≥ 3:1).

_Generated by `scripts/controls-docs-contrast.fsx` — do not hand-edit._
