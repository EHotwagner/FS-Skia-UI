# Interactive visible window — applicability (feature 102, R8)

status=not-applicable
mode=render-only
window-visible=not-applicable
accessible-window=not-applicable
first-frame-presented=not-applicable
self-closed-for-evidence=not-applicable

R8 adds no interactive, persistent, or graphical entry point. It is a documentation/internal-comment
honesty pass — roadmap report prose plus descriptive source comments — with zero behavior change. There
is no window to make visible, accessible, present a first frame, or self-close for evidence. Rendering
output is byte-identical to pre-R8, so no window-visibility obligation arises (see
[window-visibility.md](./window-visibility.md)).
