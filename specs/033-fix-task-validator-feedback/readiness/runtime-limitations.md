# Runtime Limitations

Runtime FS.Skia.UI behavior is out of scope for this governance feature.

The repository runtime baseline remains .NET 10 desktop with Vulkan and SkiaSharp preview constraints. Unsupported macOS/mobile/browser paths and no software-renderer fallback are not changed by this feature.

No rendering, viewer, input, layout, or runtime package behavior was modified. Advisory FS.Skia.UI capability guidance is documentation-only and does not add runtime validation or package dependencies.
