# Contract: Task Guidance Scan

## Scope

This contract covers author-facing task-generation guidance in repository and preset templates.

## Required Behavior

- Guidance must document the `Complete readiness notes` title prefix and explain that it suppresses capability expectation checks for setup/readiness aggregation tasks.
- Guidance must document the enforced Spec Kit trigger groups for:
  - graph validation
  - evidence audit
  - task generation
  - implementation loading
  - constitution work
- Guidance must distinguish blocking trigger rules from advisory examples and non-enforced authoring suggestions.
- Guidance must include at least three safe setup-title examples for tasks that cite required readiness filenames.
- Guidance must avoid presenting obsolete-only examples as currently enforced failures.
