## Accepted Row Requirements

- `task_id`: task identifier from `tasks.md` and `tasks.deps.yml`.
- `declared_skill_id`: exact skill id from structured `skillist`.
- `resolved_skill_path`: exactly one readable `SKILL.md`.
- `load_result`: `loaded`, or `exception` with the required reviewer fields.
- `loaded_at`: UTC timestamp captured when the skill instructions were read.
- `work_started_at`: UTC timestamp captured before the task's first code or
  readiness edit.
- `evidence_path`: this file or a task-specific verification log under
  `readiness/`.
- `exception`: `none`, or task, skill, reason, approving reviewer, and
  compensating evidence.

## Rejection Examples

- `T017: declared skill speckit-implement has no pre-work load evidence`
- `T017: skill speckit-implement loaded after work started`
- `T017: declared skill fs-skia-layout resolves to multiple SKILL.md files`
