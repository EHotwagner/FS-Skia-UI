Feature 104 adds no interactive, persistent, or graphical entry point. It is a documentation-currency
(skill-honesty) pass over three Markdown skill files plus the generated `.claude/skills/**` mirror and
`skillist-reference.md`, with zero behavior change. There is no window to make visible, accessible,
present a first frame, or self-close for evidence. Rendering output is byte-identical to pre-104, so no
window-visibility obligation arises (see [window-visibility.md](./window-visibility.md)).
