# Window options (feature 095)

No window is created by this render-only feature, so each window option is recorded as
not-applicable. No unsupported window setting is requested, so nothing is silently ignored.

option=resize: not-applicable (no window)
option=maximize: not-applicable (no window)
option=startup-state: not-applicable (no window)
option=startup-position: not-applicable (no window)
option=backend: not-applicable (no live backend window; rendering parity is structural)
note: deterministic render-only feature; no host window options are exercised
  ([[fs-skia-evidence-mode]]).
