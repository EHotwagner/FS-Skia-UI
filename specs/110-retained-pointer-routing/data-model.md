# Phase 1 Data Model: Retained-Frame Pointer Routing

This feature adds **one** public field and **one** internal lookup; everything else
is reuse of existing retained entities. No new package, no MVU type change.

## Entity: `FrameMetrics` (public, `ControlsElmish.fsi`) — extended

Post-feature shape (current fields + the new one):

| Field | Type | Semantics |
|-------|------|-----------|
| `ProductModelChanged` | `bool` | A product message changed the model this frame (unchanged). |
| `ViewCalled` | `bool` | `host.View` actually ran this frame. **Narrows**: routing via the retained path does NOT set it true (FR-008). |
| `FullRenderCount` | `int` | Count of genuine `host.View` + `Control.renderTree` materializations. **Narrows**: routing via the retained path does NOT increment it (FR-008). A model-driven re-render still does. |
| `RemeasuredNodeCount` | `int` | From the retained step's `WorkReduction` (unchanged). |
| `PointerSamplesReceived` | `int` | Raw native samples incl. deferred moves (unchanged). |
| `PointerMovesProcessed` | `int` | ≤ 1 per burst frame (unchanged, FR-012). |
| **`FullRenderFallbackCount`** | **`int`** | **NEW (FR-009).** How many times retained routing fell back to a full render *to route an event* this frame. MUST be `0` for every normal scripted pointer scenario. Deterministic, golden-asserted. XML-doc required. |
| `FrameDuration` | `TimeSpan` | Real wall-clock; excluded from goldens (unchanged). |

**Construction/read sites to update** (every one, in the same change, or the build
breaks): `ControlsElmish.fs:804` (`emitFrameMetrics`), `1076` (`zero`), `1107`
(move), `1144` (tick), `1162` (key), `1178` (discrete); test serialize
`tests/Elmish.Tests/Feature109CorpusTests.fs:153`; surface baseline
`readiness/surface-baselines/FS.Skia.UI.Controls.Elmish.txt` + per-package
baselines (regenerated by `RefreshSurfaceBaselines`).

**Validation rules**: `FullRenderFallbackCount >= 0`; `= 0` on all normal corpus
scenarios (SC-005); `>= 1` only in the deliberately forced-fallback case (SC-006).
Adding the field is a **breaking** `.fsi` change (Tier 1) but not a behavior change
(FR-011): no pixel/layout/dispatch outcome differs.

## Entity: Retained-id → authored-control-id lookup (internal, `RetainedRender`)

| Aspect | Value |
|--------|-------|
| Visibility | internal (declared in `RetainedRender.fsi`, hidden from consumers). |
| Input | a `RetainedId` from `retainedHitTest`. |
| Output | the authored `ControlId` whose `EventBindings` entry must fire (`ControlId option`). |
| Construction | built during `RetainedRender.step` from the retained node tree + the frame's `BoundIds`, reproducing `Control.nearestAuthored`'s keyed-OR-in-`BoundIds` climb from retained identity (feature 098 scheme). |
| Reached by | `FS.Skia.UI.Controls.Elmish` within the assembly boundary; tests via `InternalsVisibleTo`. |

**Validation rule**: for every pointer event over every test scene, the authored id
this lookup returns equals the id `nearestAuthored` returns over the oracle's
rendered tree (FR-005/FR-006). Unkeyed same-kind siblings resolve to distinct
retained ids and therefore distinct authored bindings (FR-005).

## Entity: Retained route read set (internal, `Controls.Elmish`)

The retained route reads only already-produced retained data — no fresh render:

- `RetainedRender<'msg>.Layout` — cached `LayoutResult` fed to `Pointer.update`.
- `retainedHitTest x y retained` — `RetainedId option` under the point.
- The retained frame's `ControlRenderResult` (newly retained `s.Render`, R5):
  `EventBindings`, `BoundIds`, `Bounds`.
- The R1 lookup — `RetainedId → ControlId`.

## Entity: Full-render routing oracle (public, preserved)

`routeInteractivePointer` (`ControlsElmish.fsi:205`) is **retained unchanged** as
the parity oracle and the counted last-resort fallback. It is no longer wired as
the *normal* live route; `runInteractiveApp` and `Perf.runScript` call the internal
retained route, falling back to this oracle only on an unresolved event (counted by
`FullRenderFallbackCount`).

## State / lifecycle

No new persistent state. The retained route is stateless beyond the existing
`pointerState` ref (threaded across samples, unchanged) and the newly-retained
`s.Render` ref (R5). Per-identity focus/animation/text state in
`RetainedRender.StateByIdentity` is unchanged.
