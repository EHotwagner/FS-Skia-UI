# Contract: `ControlsDocCoverageCheck` governance gate

**Type**: FAKE target / routed governance gate (single home: `build/Governance/**`).
**Tier**: routes under the controls-public-surface rule in `Routing.fs`.

## Inputs

- All `src/Controls/**/*.fsi` files (the Controls package public surface).
- No flags. Deterministic; no network; no `.fake` concurrency hazard beyond the shared
  `.fake` state every FAKE target has (run sequentially per repo rule).

## Behavior

Pure analysis (`ControlsDocCoverage.analyze : unit -> DocFinding list`) executed at the
`Engine/Interpret.fs` edge:
1. Enumerate the `.fsi` files (Globbing).
2. Associate each leading `///` block with the next `val`/`type`/`member` declaration.
3. Emit a `DocFinding` for every member violating the predicate (placeholder / empty /
   duplicate-only — see `doc-comment-standard.md` and research D2).
4. Render `readiness/doc-coverage.md` (enumerated surface + findings, or explicit pass).

## Pass / fail criteria

- **PASS** ⇔ finding list is empty: every public Controls member has a substantive,
  non-placeholder, non-empty summary, and no summary is a duplicate-only reworded
  placeholder. Report states `findings=0` over `N` members across `M` files.
- **FAIL** ⇔ any finding: target returns non-zero, report lists each `File:Line
  Identifier — Reason — Detail`. Build is blocked.

## Wiring obligations (must all hold or the gate is invalid)

- `Targets.fs`: `ControlsDocCoverageCheck` present in the `Target` DU, `allTargets`,
  `name` map, `directPrerequisites` (`[]`), and `routableGates`.
- `Routing.fs`: gate listed in the controls-public-surface rule's required gates.
- `validation.contract.yml`: regenerated by `RefreshSurfaceBaselines`;
  `TargetMetadataDrift` passes (no hand edit).
- `AgentValidation.knownGates`: includes the gate (derived from `routableGates` — free
  once `routableGates` is updated).

## Test contract (red-before / green-after)

- A governance test plants a `.fsi` fixture containing a placeholder summary →
  `analyze` returns a `Placeholder` finding (RED proves the gate detects the real
  failure mode).
- The same test over a fixture with substantive summaries → 0 findings (GREEN).
- After the 186 live placeholders are replaced, `analyze()` over `src/Controls/**`
  returns `[]` (the feature's SC-002 acceptance).

## Anti-evasion

The `DuplicateOnly` reason fails a mechanically-reworded placeholder shared across many
members with no member-specific token, so "find/replace the boilerplate sentence with a
different generic sentence" does not pass the gate.
