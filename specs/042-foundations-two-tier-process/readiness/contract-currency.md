# SC-007 — `validation.contract.yml` single source / currency check

`validation.contract.yml` is generated from `build/Governance/Routing.fs` via
`ContractView.render`; the pure `ContractView.currencyDrift` is folded into
`TargetMetadataDrift` (detection) and `ContractView.render` into
`RefreshSurfaceBaselines` (regeneration) — research R1.

Live demonstration (sequential FAKE runs, captured):

| Step | Command | Result |
|------|---------|--------|
| regenerate | `./fake.sh build -t RefreshSurfaceBaselines` | exit 0 — emits the contract from `Routing.fs` |
| accept | `./fake.sh build -t TargetMetadataDrift` | **exit 0** — fresh contract is current |
| reject | hand-edit `validation.contract.yml`, then `./fake.sh build -t TargetMetadataDrift` | **exit 1** — stale contract rejected |
| regenerate | `./fake.sh build -t RefreshSurfaceBaselines` | exit 0 — currency restored |
| re-accept | `./fake.sh build -t TargetMetadataDrift` | **exit 0** — passes again |

The reject diagnostic (captured from the failed `TargetMetadataDrift`):

    -> validation.contract.yml is stale  regenerate from Routing.fs via ./fake.sh build -t RefreshSurfaceBaselines
    Status: Failure

After the regenerate/re-accept cycle, `git diff --stat validation.contract.yml`
shows the file returns to the generated bytes: the hand-edit was the only
divergence and `Routing.fs` is the sole source of truth.

The generated contract retains every field its existing consumers read — the
feature-028 `src/Lib/AgentValidation.fs` parser and Governance.Tests require per-rule
`paths:`, `feature_concerns:`, `required_gates:`, `expected_artifacts:`,
`timeout_class:`, and `failure_owner:`, plus the tier `default_gates`/`authority`
and the `defaults` block — so demoting the file to a generated view did not break
any consumer (FR-007); the full Governance.Tests suite stays green (311/311).

Pure-core tests (ContractViewTests.fs, green): `currencyDrift (render rules ids)
rules ids = None`; `currencyDrift <hand-mutated> rules ids = Some _` (diagnostic
names "regenerate from Routing.fs").
