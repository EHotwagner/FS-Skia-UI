# Catalog single source over all 47 controls (071) — T012

## What changed

`build/Governance/CatalogGen.fs` `catalogFacts` grew from the **6** reference 065
facts to **all 47** catalog ids (FR-001). Each fact's values were copied from the
matching hand-maintained `catalog.yml` / `Catalog.fs` row (id, display name,
category, module, purpose, required attributes, events, accessibility role) via a
small `fact` constructor, so the regenerated bytes equal the existing rows.

The renderers' chart/data-grid evidence special-case was generalized (FR-004) from
the single `fact.Id = "data-grid"` guard to membership in the **six**
evidence-carrying ids:

```
data-grid · line-chart · bar-chart · pie-chart · scatter-plot · graph-view
```

Exactly those six rows append `|> withChartDataGridEvidence` (F#) and the
chart/data-grid evidence path (YAML); no other row does — matching
`grep withChartDataGridEvidence src/Controls/Catalog.fs` before regeneration.

## Regeneration

`./fake.sh build -t RefreshSurfaceBaselines` splices each fact into its
`BEGIN/END GENERATED: typed-catalog/<id>` region in both `src/Controls/catalog.yml`
and `src/Controls/Catalog.fs`. After regeneration **all 47 rows are generated**
(47 regions in each file) and **zero rows are hand-maintained outside the markers**.
The 41 newly-marked rows are a markers-only diff except three intentional
single-source canonicalizations:

- `custom-control` `RequiredAttributes = []` in both files — bridge-typed
  (`Widget.ofControl`), no fabricated required attribute (FR-006 / R3).
- `rich-text` YAML `evidence` normalized to the base evidence list (the generator
  is now the single source for the YAML evidence pointer).

## Enforcement

- `ControlsCatalogGenerationCheck` enforces currency over all 47 facts. A
  hand-edit to any generated region flips it to `Stale`/`Missing` and the gate
  fails naming the stale `typed-catalog/<id>` region **and**
  `./fake.sh build -t RefreshSurfaceBaselines` (proven in
  `readiness/logs/us1-red-green.md`, T011).
- The `066` fixture-iteration cross-check
  (`tests/Controls.Tests/CatalogTests.fs`) reads one
  `Catalog.fs.<id>.txt` + `catalog.yml.<id>.txt` pair per fact (47 pairs, golden
  bytes captured from the real renderer) and asserts `catalogFacts` ids == the 47
  typed ids, with each non-`custom-control` required attribute (PascalCased) a
  field of that control's typed `Props` record. `custom-control` is excluded from
  the Props-field assertion (bridge-typed, C10).
