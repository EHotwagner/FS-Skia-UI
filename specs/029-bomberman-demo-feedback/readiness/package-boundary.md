# Package Boundary

Status: reviewed.

Boundary decisions:

- Scene remains dependency-light and does not reference viewer, host, keyboard, controls, Silk, SkiaSharp, or Elmish packages.
- Layout depends on Scene and Yoga.Net only.
- SkiaViewer owns viewer launch and screenshot capture.
- Testing owns report validation helpers.
- Elmish owns adapter transition/effect mapping.

Validation:

- `readiness/scene-layout-authoring.md`
- `readiness/package-surface-check.log`
- `readiness/dependency-report.md` when generated by broader validation
