The new package surface + maintainer-verify Route artifacts and which gate writes / checks
each.

## New package surface obligations

- `FS.Skia.UI.SkillSupport` registered in `PerPackageSurface.packagesInScope` +
  `packageSourceDir` (10th in-scope package) and in `Front.Helpers.packProjects` (packed by
  `PackLocal`, shipped to the template).
- Surface baseline `readiness/per-package-surface/FS.Skia.UI.SkillSupport.fsi.txt` is

  Principle VII).

  circularity).
