# Governance Scope

- Tier: Tier 1 governance contract change for Spec Kit task metadata and workflow guidance.
- Public runtime API impact: none. No `.fsi` signature or package API is introduced or changed.
- Package impact: none. No package identities, versions, contents, or dependency versions changed.
- Affected workflow surfaces: task templates, task dependency metadata, task-generation guidance, implementation guidance, constitution guidance, evidence graph validation, and generated guidance validation.
- Principle IV applicability: not applicable. This feature changes static governance artifacts and validation scripts, not a stateful runtime or I/O workflow exposed through library APIs.
- Synthetic evidence: none planned and none used for completed tasks. Validation fixtures are real filesystem inputs to the production readiness validator.
