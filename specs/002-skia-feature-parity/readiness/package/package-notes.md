# Package Notes

The feature produces three independently referenceable packages:

- `FS.Skia.UI`: core Elmish viewer, scene DSL, diagnostics, screenshots, and Vulkan host.
- `FS.Skia.UI.Charts`: pure chart and DataGrid scene builders over `FS.Skia.UI`.
- `FS.Skia.UI.Layout`: pure layout and graph scene builders over `FS.Skia.UI`.
