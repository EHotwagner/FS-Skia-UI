  by exactly (dx,dy): decoded lit-pixel bounding box of the translated render = base bbox +
  (50,30) on all four edges (uniform offset, proven on a non-rectangular Path kind).

  lit-pixel bbox as Translate(55,0)·s.

  size => wider lit glyph extent); a bare Text still renders pixels unchanged (back-compat).
- Structural: describe reports SizedTextElement / TranslateElement.

and routes SizedText through drawTextWithFallback at the explicit size; the existing Text case
is unchanged. Both new cases are handled in the exhaustive describe/diagnostics/scaleNode/
paintNode matches.
