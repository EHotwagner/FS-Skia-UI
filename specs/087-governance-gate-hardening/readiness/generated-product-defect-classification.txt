## The classification machinery (single source, EvidenceFormatSchema)
- classifyGeneratedCategory maps each failure category to a StepClassification: a genuine
  host obstacle (UnsupportedHost / Completed) -> Environment; every product/contract failure
  category (PackageDrift, RestoreFailure, SemanticTestFailure, ViewerStartupFailure,
  SceneEvidenceFailure, WindowDiagnosticsFailure, WindowOptionsFailure, VisualEvidenceFailure,
  PersistentLaunchDiagnosticFailure) -> ProductDefect.
- generatedProductVerdict aggregates per-step results: ProductDefectFail iff ANY step failed
  as ProductDefect; else EnvironmentNonAuthoritative if any step failed; else ProductPass.
- runGeneratedConsumerValidation attaches a { Step; Passed; Classification; PackageSet } result
  to each step (package-set=Pinned) and the final fail decision uses the verdict: it fails on
  ProductDefectFail, prints EnvironmentNonAuthoritative non-authoritatively, passes ProductPass.
- Because the product-defect steps run LAST in fixed order, a product defect always survives in
  the final category, so an earlier environment obstacle can never mask it.
