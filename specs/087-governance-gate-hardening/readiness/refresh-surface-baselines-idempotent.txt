## What changed (T017)
PerPackageSurface.captureBaselines (edge) + serializeBaseline (pure) were folded into
RefreshSurfaceBaselines via the new RegeneratePerPackageBaselines effect. The refresh now
regenerates readiness/per-package-surface/<PackageId>.fsi.txt for every in-scope package
(11 packages) in the same run as the cross-package/api-surface/skill baselines — the
per-package snapshots are no longer a hand-maintained side artifact.

The canonical on-disk form is `normalize(<package .fsi text>) + "\n"` — exactly one
trailing newline. `normalize` already drops trailing blanks/blank-line runs, so the write
is a byte-stable fixed point.
