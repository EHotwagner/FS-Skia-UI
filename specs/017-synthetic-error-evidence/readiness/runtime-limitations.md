# Runtime Limitations

This governance feature has no runtime package, renderer, or platform support
change. Existing boundaries remain in force:

- .NET 10 desktop governance tooling.
- Vulkan and SkiaSharp preview runtime limitations are unchanged.
- unsupported macOS/mobile/browser targets remain unsupported.
- no software-renderer fallback is introduced.
- no package/API/runtime support expansion is included.
