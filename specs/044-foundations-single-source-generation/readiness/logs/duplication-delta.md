# Duplication Delta (SC-007) vs the Stage-0 baseline

Stage-0 baseline (`docs/reports/_baselines/2026-05-31-foundations.md`):
- `.claude/skills` ↔ `.agents/skills` was a hand-synchronized **byte-identical mirror**
  of synchronized peers, **5,854 combined lines** of governance-skill prose, with
  `SkillSyncCheck` guarding only **6** of the slugs (19 unguarded) and the redundant
  `SkillExamplesCheck` tangling the cookbook blocks.

After feature 044:
- `.agents/skills/**` is the **single canonical source** (the ~4058-line
  `.claude/skills/**` copy is now **generated by enumeration** from it, covering **all 25**
  skills, plus a single tree-level `GENERATED.md` provenance manifest).
- The hand-maintained second copy + its drift-check collapse to **one canonical source +
  a generator** (`SkillTreeGen`); the entire `.claude/skills/**` line count is no longer a
  hand-maintained duplicate — it is reproduced byte-for-byte at gate time.
- `SkillExamplesCheck` (the separate ~90-line tangler gate + `SkillExamples.fs/.fsi` module +
  its test suite) is **retired**, removing that whole peer mechanism.

Net: the ~5,854-line two-copies-plus-a-drift-check skill-mirror duplication class is
eliminated — one canonical tree (~4058 lines) + a pure generator + a currency gate.
