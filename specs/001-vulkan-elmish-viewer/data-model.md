# Data Model: Vulkan Elmish Viewer

## ViewerConfiguration

Represents startup options for a viewer instance.

**Fields**

- `title`: Window title.
- `initialSize`: Width and height in physical or logical pixels as defined by the host.
- `clearColor`: Optional frame clear color.
- `targetFrameRate`: Optional requested frame cadence.
- `diagnostics`: Diagnostic verbosity and sink settings.

**Validation Rules**

- Must not contain renderer selection or fallback selection.
- Size must be positive.
- Unsupported platform or renderer capability is reported as a startup diagnostic.

## Scene

Declarative visual content generated by the Elmish view function.

**Fields**

- `nodes`: Ordered visual nodes.
- `background`: Optional background paint.
- `metadata`: Optional labels for diagnostics or screenshots.

**Relationships**

- Produced from `Model` by `view`.
- Consumed by `RenderFrame` effects.

**Validation Rules**

- Invalid resources or unsupported drawing features produce diagnostics, not silent frame loss.

## VisualNode

Single renderable scene item.

**Fields**

- `kind`: Geometry, text, image, effect, layout container, chart, or composition node.
- `bounds`: Optional layout bounds.
- `paint`: Optional fill/stroke/text styling.
- `children`: Child nodes for composition and layout.

## Model

Durable Elmish application state owned by a viewer program.

**Fields**

- Application-defined state.
- Viewer lifecycle state such as not started, initializing, running, failed, or shutting down.
- Latest render diagnostic, if any.

**State Transitions**

- `NotStarted -> Initializing`: startup requested.
- `Initializing -> Running`: Vulkan renderer initialized and first scene accepted.
- `Initializing -> Failed`: Vulkan initialization failed.
- `Running -> Running`: input, subscription, resize, render, or screenshot message processed.
- `Running -> ShuttingDown`: close requested.
- `ShuttingDown -> NotStarted`: resources disposed.

## Msg

Events accepted by the Elmish update function.

**Kinds**

- User input: keyboard, pointer, resize.
- Lifecycle: start, initialized, close, shutdown complete.
- Rendering: frame requested, frame rendered, frame failed.
- Screenshot: capture requested, capture completed, capture failed.
- Subscription: timer or external message.
- Diagnostic: renderer or application diagnostic reported.

## Effect

I/O requested by pure update logic and interpreted at the host edge.

**Kinds**

- `InitializeRenderer`
- `RenderFrame`
- `CaptureScreenshot`
- `StartSubscription`
- `StopSubscription`
- `Shutdown`
- `ReportDiagnostic`

**Validation Rules**

- Effects are data or Elmish commands; `update` does not execute Vulkan, filesystem, clock, or windowing I/O directly.

## ViewerEvent

Input and lifecycle information from the windowing layer.

**Fields**

- `timestamp`
- `eventKind`
- `payload`

**Relationships**

- The host interpreter maps viewer events to `Msg`.

## RenderDiagnostic

Structured information for startup and runtime failures.

**Fields**

- `severity`: Info, warning, error, fatal.
- `stage`: Platform check, instance creation, device selection, surface creation, swapchain creation, Skia context creation, frame render, screenshot capture, shutdown.
- `message`: Human-readable message.
- `cause`: Optional exception or native error detail.
- `isFallbackAttempt`: Must be false for valid operation; fallback attempts are rejected diagnostics.

## ScreenshotRequest

Request to capture the current visible frame.

**Fields**

- `destination`: Output path.
- `format`: Supported image format.
- `requestedAt`: Timestamp or frame index.

**Validation Rules**

- Capture before first successful frame returns a diagnostic.
- Destination write failures are reported without crashing pure update logic.
