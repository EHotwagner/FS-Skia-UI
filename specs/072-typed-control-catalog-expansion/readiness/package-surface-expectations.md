**Change class**: additive-only public surface (SC-004, FR-008). No existing
declaration changes; no legacy `*.create`/`Attr` builder is removed or deprecated.

## Additive public-surface delta (`FS.Skia.UI.Controls`)

New files `src/Controls/Widgets/Buttons.fsi` and `src/Controls/Widgets/Pickers.fsi`
add, all under the existing `FS.Skia.UI.Controls.Typed` namespace:

- Value records: `SplitButtonItem` (`{ Key; Label }`), `ColorSwatch`
  (`{ Name; Color }`, `Color = FS.Skia.UI.Scene.Color`).
- `Props` records: `ToggleButtonProps<'msg>`, `SplitButtonProps<'msg>`,
  `DatePickerProps<'msg>`, `TimePickerProps<'msg>`, `ColorPickerProps<'msg>`.
- Modules each exposing `defaults` + `view : Props<'msg> -> Widget<'msg>`:
  `ToggleButton`, `SplitButton`, `DatePicker`, `TimePicker`, `ColorPicker`.

No `obj`-typed field and no untyped/string-named event payload appears on the new
`.fsi` (date/time = BCL `DateOnly`/`TimeOnly`; color = `Scene.Color`; events are
optional typed callbacks). The `UntypedValue` carrying a swatch's `Color` exists
only in the `.fs` lowering, never on the signature.
