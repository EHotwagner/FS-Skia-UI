## Additive public-surface delta

### `FS.Skia.UI.Scene` — new `src/Scene/Animation.fsi`

All under the existing `FS.Skia.UI.Scene` namespace:

- Value types: `Easing` (DU: `Linear`/`EaseIn`/`EaseOut`/`EaseInOut`), `Transform`
  (motion-labelled record), `Tween<'a>`, `Animation`, `AnimationState<'a>`.
- Modules: `Easing` (`apply`, `Default`), `Transform`
  (`identity`/`isIdentity`/`lerp`/`toPerspectiveTransform`), `Tween`
  (`progress`/`sample`), `Animation`
  (`lerpFloat`/`lerpColor`/`empty`/`applyAt`/`sampleFrames`/`isSettled`),
  `AnimationState` (`create`/`advance`/`retarget`/`value`/`isActive`).

No `obj`-typed field and no stringly-typed value: properties, easing, and durations are
strongly typed (`Tween<'a>`, `Easing`, `System.TimeSpan`).

**Contract-resolution note (`AnimationState.Interp`).** The pinned contract record
listed six data fields, but `AnimationState.create` takes an `interp` while
`advance`/`value` (which must recompute `Current` for the generic `'a`) do not — the
six-field record had nowhere to store it. The only internally-consistent resolution is
a seventh field `Interp: 'a -> 'a -> float -> 'a` carrying the supplied interpolant.
This is **additive and strongly typed**; it is surfaced in the regenerated baselines
and is the documented deviation from the contract's illustrative six-field shape (the
contract grants "exact spelling … tasks-phase detail" latitude). `isActive` carries the
inferred `when 'a: equality` constraint (it compares `Current <> Target`).

### `FS.Skia.UI.Elmish` — new `src/Elmish/AnimationTick.fsi`

Under the existing `FS.Skia.UI.Elmish` namespace:

- `type AnimationTick = AnimationTick of System.TimeSpan` — the per-frame message.
- `module Animation` with `tickSubscription : isAnimating -> toMsg -> interval -> 'model -> Sub<'msg>`.

`tickSubscription`'s signature is more complete than data-model's illustrative
`isAnimating -> Sub<'msg>` (it also takes the msg mapper, frame interval, and model so
it plugs into `Program.withSubscription`) — a tasks-phase detail the contract leaves
open; the gated guarantees (active-emits / settled-silent, additive-only) hold.
